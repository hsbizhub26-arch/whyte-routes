## Bugs

### [P1] Locate button clipped by the bottom drawer on the Home / My Route map
- **Symptom:** On the driver Home / "My Route" dashboard, right after sign-in, the
  yellow locate / recenter button (bottom-right of the map) is partially hidden
  behind the floating bottom drawer/widget (the "Start Shift / Start Navigation"
  card). It's the first thing a driver sees after login, so it reads as a layout bug.
- **Where:** The base map is [`DriverMapView`](WHYTE ROUTES/Views/Driver/DriverMapView.swift),
  embedded in [`DriverDashboardView`](WHYTE ROUTES/Views/Driver/DriverDashboardView.swift),
  which overlays the bottom drawer on top of it. The locate button sits too low and
  the drawer covers its lower edge. Check the owner map
  ([`LiveFleetMapView`](WHYTE ROUTES/Views/Owner/LiveFleetMapView.swift)) for the same overlap.
- **Fix direction:** Give the locate button bottom clearance equal to the drawer
  height + bottom safe-area inset so it always sits above the drawer. Reuse the
  approach already shipped for the navigation bottom card in commit `b5277d2`
  (`navigationBottomInset` / measured `bottomCardHeight` via a `PreferenceKey` in
  `DriverNavigationScreen`) — measure the drawer height rather than hardcoding a pad,
  since the drawer grows/shrinks with route state.
- **Priority:** High.
