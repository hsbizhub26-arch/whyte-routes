## Resolved

### [P1] Map locate/zoom controls hidden behind bottom drawers — RESOLVED
- **Symptom:** The circular locate / re-center button (and the zoom column) on the
  map was vertically centered on the right edge, so a bottom sheet rising over the
  map swallowed it. On the owner Home / Fleet Dashboard the "Dashboard" panel hid
  the locate button entirely and clipped the zoom control; the driver My Route
  status card posed the same risk.
- **Fix:** Re-anchored the control column to `.bottomTrailing` with a **dynamic**
  bottom clearance that always sits above the tab bar + home indicator and lifts
  above whatever bottom card/panel is showing (measured, not hardcoded).
  - Owner fleet map ([`LiveFleetMapView`](WHYTE ROUTES/Views/Owner/LiveFleetMapView.swift) +
    [`OwnerDashboardView`](WHYTE ROUTES/Views/Owner/OwnerDashboardView.swift)) — commit `de2e7e0`.
  - Driver map ([`DriverMapView`](WHYTE ROUTES/Views/Driver/DriverMapView.swift) +
    [`DriverDashboardView`](WHYTE ROUTES/Views/Driver/DriverDashboardView.swift)) — hardened
    proactively in the same pass; controls now clear the measured status card.
- **Verified:** simulator build clean (zero errors/warnings in the touched files);
  confirmed on-device in both collapsed and open/expanded states, both views.
